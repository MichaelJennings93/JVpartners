# JV Partners — Website

Marketing website for JV Partners, a partner-led strategic consultancy and advisory firm (transformation, integration, M&A advisory, HR & people, talent acquisition).

## Stack
React 19 · TypeScript · Vite · Tailwind CSS · GSAP · Framer Motion · Three.js

## Development
```bash
npm install
npm run dev      # local dev server
npm run build    # production build → dist/
```

## Deployment
Pushes to `main` deploy automatically to GitHub Pages via `.github/workflows/deploy.yml`. See `DEPLOYMENT.md` for details and custom-domain setup.
